LeetCode 2582. 递枕头：数学规律与 O(1) 解法

题目描述

有 n 个人站成一排，编号从 1 到 n。枕头最初在第 1 个人手里。每一秒，枕头会传递给相邻的人。如果枕头到达了队首（第 1 个人）或队尾（第 n 个人），传递方向就会反转。给你 n 和 time，返回 time 秒后枕头在谁手里。

示例：

  • 输入：n = 4, time = 9，输出：4
  • 输入：n = 3, time = 2，输出：3

解题思路

直接模拟传递过程当然可以，但 time 可能很大，模拟会超时。观察传递规律，可以发现它是一个周期性的往返运动。

边界情况

当 time < n 时，枕头还没有到达队尾，直接返回 time + 1 即可，因为初始位置是 1，第 time 秒在 time + 1。

代码实现

示例解析：n = 4, time = 9

  • time = 9，n = 4，不满足 time < n，进入 else。
  • ch = 9 / (4 - 1) = 9 / 3 = 3.0，是整数，所以 ch = 3。
  • arry = 3 * 4 - (3 - 1) = 12 - 2 = 10。
  • ch 是奇数（3），走 else 分支：return 4 - (10 - 9) + 1 = 4 - 1 + 1 = 4。
  • 结果正确，第 9 秒枕头在第 4 个人手里。

复杂度分析

  • 时间复杂度：O(1)，只进行了常数次算术运算。
  • 空间复杂度：O(1)，仅使用了几个变量。

总结

这道题的核心是找到传递过程的周期性规律。通过将往返运动“拉直”，并用数学公式计算经过的半周期数，可以避免模拟整个传递过程，实现 O(1) 的高效解法。需要注意边界条件（如 time < n）和浮点数除法的取整处理。
